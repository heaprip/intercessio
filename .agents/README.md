# Shared agent workspace

`.agents/` — общая оперативная память помощников, работающих с репозиторием.
Она не заменяет архитектурную документацию.

- `memory/current.md` — где мы сейчас и какой следующий шаг;
- `memory/open-questions.md` — вопросы, которые нельзя незаметно превратить в
  решения;
- `memory/context.md` — короткая памятка для быстрого входа в проект.

Долговечные знания находятся в `docs/`. Принятые решения находятся только в
ADR. Если оперативная память противоречит ADR или коду, помощник должен отметить
конфликт, а не выбирать удобную версию.

После compaction или иной потери контекста помощник перечитывает эти файлы и
релевантные ADR. Если восстановленные источники недостаточны или противоречат
друг другу, он спрашивает автора, а не заполняет пробел правдоподобным
предположением.

Перед завершением существенной сессии помощник обновляет `memory/current.md` и
убирает из него устаревшие детали. История работы принадлежит Git; здесь нужен
только актуальный снимок.
