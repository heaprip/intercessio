# Текущее состояние


## Сейчас

Предметная рамка пересматривается. Черновик новой рамки —
`docs/proposals/0001-game-framing.md`, статус НЕ ПРИНЯТО: пошаговая
игра-песочница про законотворчество, где игрок задает нормы, институты и людей,
двигает мир шагами и видит, каким способом его конструкция ломается.

Метацель автора: полигон для отработки AI-стороны крупного приложения —
событийная архитектура, разнородные потоки, оркестрация нескольких LLM-ролей и
позднее аналитика. Предметная область выбрана как средство.

Старые документы `vision.md`, `glossary.md` и `context-map.md` описывают
предыдущую рамку (разбор одного прошения) и еще не переписаны.

В рабочем дереве лежит выброшенный код (`cmd/`, `internal/core`) и `compose.yml`
с Postgres. Это проба пера, а не решение: тест намеренно падает, автор все
удалит. На документацию это не влияет.

## Не делать пока

- не переписывать `vision.md`, глоссарий и карту контекстов до решений автора;
- не углубляться в юридическую формализацию: правовая часть намеренно мелкая,
  из нее сохраняются только версии норм и действие во времени;
- не строить аналитический контур («цензор») — он отдельный поздний этап, но
  требование аудита из `principles.md` §7 сохраняется с самого начала;
- не позволять одной LLM играть конфликтующие роли в одном security context;
- не объявлять YDB, AWS, OpenFGA datastore или managed workflow engine
  окончательным выбором;
- не строить общий workflow/outbox/agent framework до первого сценария;
- не использовать HTTP/gRPC для общения модулей внутри монолита.
