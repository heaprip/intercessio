# Ubiquitous language

Статус: Draft  

Словарь описывает смысл симуляции, а не названия таблиц или визуальные образы.
Английский термин в скобках — кандидат для идентификаторов в коде.

| Термин | Рабочее значение | Не смешивать с |
| --- | --- | --- |
| Человек (`Person`) | Симулируемый субъект с идентичностью, состоянием, историей и целями | реальным пользователем приложения или автоматически гражданином |
| Actor | Человек, институт или технический исполнитель, совершающий типизированное действие | LLM model instance и ролью как набором полномочий |
| Желание (`Desire`) | Внутренняя цель человека, которая может быть неполной или противоречивой | поданным запросом и правом |
| Запрос (`Petition`) | Зарегистрированное требование рассмотреть определенный outcome | доказанным фактом, командой исполнения и решением |
| Дело (`Case`) | Версионируемая рамка рассмотрения запроса или спора с участниками и материалами | человеком и окончательным решением |
| Утверждение (`Claim`) | Проверяемое высказывание участника о факте или норме | установленным фактом |
| Установленный факт (`EstablishedFact`) | Утверждение, принятое надлежащей процедурой с provenance | текстом LLM, слухом или внешним вводом |
| Нормативный документ (`NormativeDocument`) | Версионируемый источник общих правил с authority, периодом действия и местом в иерархии | решением отдельного дела |
| Конституция (`Constitution`) | Высший contract симуляции о статусах, институтах, компетенциях и изменении норм | prompt и hard-coded исключением без основания |
| Кодекс (`Code`) | Систематизированный нормативный документ ниже конституции | набором application conditionals без версии |
| Норма (`Norm`) | Адресуемое правило внутри нормативного документа | рекомендацией или предсказанием LLM |
| Право (`Right`) | Защищенная нормой возможность требовать действие или воздержание | техническим permission token и желанием |
| Обязанность (`Duty`) | Возложенное нормой требование к человеку или институту | запланированным effect intent |
| Компетенция (`Competence`) | Нормативно предоставленная роли возможность совершить тип действия | способностью LLM вызвать tool |
| Институт (`Institution`) | Устойчивая роль или орган с собственной компетенцией и ответственностью | конкретным model instance и bounded context по умолчанию |
| Рассмотрение (`Deliberation`) | Получение мотивированного предложения по делу | вступившим в силу решением |
| Решение (`Decision`) | Формальный outcome, вынесенный компетентной ролью по версии дела | рекомендацией, исполнением и объяснением |
| Вступление в силу (`Finalization`) | Переход, после которого решение разрешено исполнять | простым сохранением draft |
| Intercessio | Формальное приостановление или veto в пределах явно предоставленной компетенции | универсальной отменой любого решения |
| Пересмотр (`Review`) | Отдельная процедура проверки решения по допустимым основаниям | повторным свободным рассуждением того же actor |
| Исполнение (`Execution`) | Применение вступившего в силу решения владельцем изменяемого состояния | рассмотрением или нормотворчеством |
| Запись о проступке (`AdjudicatedOffense`) | Последствие вступившего в силу решения об установленном нарушении | обвинением, подозрением или risk score |
| Заслуга (`MeritRecord`) | Формально признанный факт или награда с provenance и authority | симпатией модели и скрытым reputation score |
| Доменное событие (`DomainEvent`) | Неизменяемый факт в прошедшем времени, возникший у владельца модели | сообщением конкретного broker |
| Команда (`Command`) | Адресованное владельцу модели намерение изменить состояние; может быть отклонена | запросом человека и событием |

## Пока не определено

- какие статусы человека существуют и кто вправе их менять;
- какие документы входят в нормативную иерархию;
- что является доказательством и какая роль устанавливает факт;
- какие решения вступают в силу немедленно, а какие требуют review window;
- является ли `Case` агрегатом или координацией нескольких владельцев;
- как называются вымышленные институты в коде и UI.

## Историческая оговорка

Римские названия не доказывают полномочия и не гарантируют соответствие
конкретному историческому периоду. Значение каждого института задается
конституцией Intercessio и этим ubiquitous language.
