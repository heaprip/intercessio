# deduction — вычислитель

Правила, факты, безопасность, стратификация, оценка, трасса, встроенные
предикаты. Не зависит ни от чего, включая предметную область: проверяется
синтетическими программами.

Основание — [[docs/decisions/norms-are-inference-rules|norms-are-inference-rules]].

## Безопасность правил

Пишется первой. Каждая переменная головы и каждая переменная под отрицанием
обязана встречаться в положительном литерале тела. Без этого правило порождает
бесконечное множество.

Проверка выполняется при сборке корпуса, а не при вычислении: небезопасное
правило является ошибкой сценария или правки игрока, и сообщать о ней надо до
хода.

## Стратификация

Строится граф предикатов с положительными и отрицательными рёбрами. Считаются
сильно связные компоненты. **Отрицательное ребро внутри компоненты означает
нестратифицируемый корпус** — у него нет однозначного прочтения, и это провал
конструкции, а не ошибка движка.

Слои — топологический порядок конденсации графа.

Тот же аппарат переиспользуется линтером, поэтому пишется один раз и живёт
здесь.

**Слои считаются по предикатам.** Уровни документов на разбиение не влияют;
норма конституции регулярно попадает в слой ниже, чем выведенный из кодекса
статус. Разрешение конфликта между нормами разных уровней — задача
[[docs/design/entitlement|entitlement]], а не эта.

## Оценка

Семинаивная: держать дельту новых фактов и подставлять в тело только её. Слои
считаются по порядку, каждый до неподвижной точки.

Отрицание вычисляется по полностью посчитанному нижнему слою; внутри слоя
отрицания нет по построению.

Период является **параметром** вычисления, а не аргументом каждого предиката:
корпус фиксируется на период, вывод идёт по срезу. Исключение — предикаты,
которые прямо проверяют прошлое состояние; они несут период явно.

Завершимость гарантирована: конечные данные, отсутствие функциональных
символов. Игрок не может написать норму, из-за которой ход не закончится.

## Встроенные предикаты

Вычисляемые отношения, разрешённые только при связанных аргументах. Список
держится **закрытым**; минимально необходимый состав:

- сравнение номеров периодов (`<`, `<=`, `=`, `>=`, `>`);
- вычитание номеров периодов.

Агрегации нет и не должно появиться: она требует собственного вида
стратификации и утянет за собой пересборку слоёв. Вместо неё действует правило
моделирования — интервалы вместо перечислений, см.
[[docs/design/corpus-and-facts|corpus-and-facts]].

## Трасса

Для каждого выведенного факта сохраняются правило и список посылок. Дерево
строится обходом назад до установленных фактов.

Трасса не является отдельной механикой объяснения: она побочный продукт
вычисления и отдаётся вместе с результатом.

## Ограничения целостности

Объявление о недопустимой комбинации выводов. Проверяется после достижения
неподвижной точки; нарушение возвращается как факт с трассой, а не как ошибка
вычисления.

## Стоп-правило

Компонент пишется под фиксированную схему предикатов, без парсера, без
текстового синтаксиса и без оптимизаций, пока правил десятки.

**Захотелось написать парсер языка норм — компонент окончен.**
