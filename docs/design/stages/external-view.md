# external-view — видно снаружи

Зависит от: [[docs/design/stages/playable-case|playable-case]], [[docs/design/stages/corpus-checks|corpus-checks]]  
Компоненты: [[docs/design/components/api|api]], [[docs/design/components/report|report]], [[docs/design/components/front|front]]

## Состав

Контракт наружу, отчёт периода, фронт: граф власти, листание периодов,
кликабельная трасса, подтверждение разобранной прозы.

Здесь же заново делается выбор транспорта — вместе с первым реальным
контрактом, см.
[[docs/decisions/proto-first-external-api|proto-first-external-api]].

## Демонстрация

Граф власти, листание периодов, кликабельная трасса.

## Гейт

Объявлен помощником (P68): партия проходит только через HTTP — создать из сценария,
увидеть стопку, находки и граф, решить карточки, прожить период, открыть прожитый
период с отчётом и журналом, получить трассу вывода; имя сценария не может быть
путём; страница отдаётся.

**Прототип готов, гейт пройден**: `internal/api`, `internal/front`, `cmd/server`,
тесты `TestAPI_GameThroughHTTP` и `TestHandler_ServesThePage`. Транспорт — HTTP с JSON
на стандартной библиотеке (P65). Посмотреть —
`go run ./cmd/server -root internal/scenario/testdata`, затем `http://localhost:8080`.

Что вскрылось:

- **ресурсно-ориентированный REST не понадобился**: фронт спрашивает виды периода и
  действует тремя глаголами — решить, прожить, объяснить;
- **петля партии переехала из команды в сессию `api`**, и `cmd/play` теперь её дубль;
- **auctor не может написать норму сам** — нет ни прозы, ни структурного редактора, а
  принять можно только карточку с готовой правкой.
