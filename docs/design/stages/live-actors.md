# live-actors — участники живые

Зависит от: [[docs/design/stages/playable-case|playable-case]]  
Компоненты: [[docs/design/components/llm-runtime|llm-runtime]], LLM-реализация [[docs/design/components/actors|actors]]

## Состав

`llm-runtime`: роли, изоляция контекста, валидация выхода по схеме, бюджет,
батч, запись и воспроизведение вызовов. Знание норм как данные — отдельно от
силы модели.

## Демонстрация

Тот же казус, разобранный моделями разной силы.

## Гейт

Записанные выходы дают точный реплей периода.
