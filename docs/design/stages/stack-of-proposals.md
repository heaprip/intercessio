# stack-of-proposals — партия идёт через стопку

Зависит от: [[docs/design/stages/corpus-checks|corpus-checks]], [[docs/design/stages/self-generated-cases|self-generated-cases]]  
Компоненты: [[docs/design/components/agenda|agenda]]

Веху завёл помощник — P43 в [[docs/proposals/prototype-decisions|журнале решений]].

## Состав

`agenda` собирает стопку из находок линтера и событий периода, auctor разбирает её,
принятые правки идут в фазу правки следующего периода.

## Демонстрация

Партия из нескольких периодов, где закон меняется только через карточки.

## Гейт

Проверка из решения
[[docs/decisions/player-works-a-stack-of-proposals|player-works-a-stack-of-proposals]]:
партия из нескольких периодов проходит только через разбор стопок, и ни одна
карточка не меняет исход дела напрямую. Кроме того: стопка не больше размера
пресета, у каждой карточки есть свидетельство, принятая правка снимает свою
находку, решённая карточка не возвращается без нового свидетельства.

**Прототип готов, гейт пройден**: `internal/agenda`, тесты
`TestStack_GameGoesThroughStacks` и `TestStack_CardReturnsWithNewEvidence`.

Демонстрация — игровая фикстура казуса о гражданстве, где исключение `C2`
объявлено принятым в периоде 30 с силой от периода 1. Размер стопки три, заглушка
auctor принимает карточки с готовой правкой и отклоняет остальные.

- **Период 30**: десять споров без порядка вокруг статуса — одна карточка, первая по
  счёту; ретроактивность `C2` с готовой правкой; судья в своём деле — претор Луций.
  Пять карточек ушли в переполнение. Правка `C2` принята и применяется в начале
  периода.
- **Период 31**: ретроактивности больше нет; приходят карточки из переполнения.
- **Период 32**: две последние.
- **Период 33**: стопка пуста — всё решено, хотя корпус не починен.

Что вскрылось:

- **группировка по корню важнее порядка**: без неё стопку заняли бы десять
  одинаковых споров;
- **правило возврата делало стопку пустеющей**: отклонённое без нового
  свидетельства молчало, и игрок, отклонивший всё, получал тишину. Теперь
  отклонённое возвращается напоминанием после тишины из пресета (P46) — и при
  заглушке, отклоняющей всё, стопка становится каруселью с периодом три. Решение о
  стопке называет оба исхода поводом для пересмотра — «слишком однообразной, чтобы в
  ней было что решать»;
- **механическая правка есть почти ни у чего**: кроме переиздания ретроактивной
  нормы, всё требует выбора — кто сильнее в споре, какой должности дать полномочие.
  Здесь и нужен советник.
