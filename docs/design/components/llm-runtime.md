# llm-runtime

Основание — [[docs/decisions/llm-does-not-grant-authority|llm-does-not-grant-authority]].

## Назначение

Вызывать модели в заданных ролях с изоляцией, бюджетом и валидацией выхода — и
уметь воспроизвести любой вызов по записи.

## Владеет

- роли и изоляция контекста;
- валидация выхода по схеме;
- бюджет и батч;
- **запись вызова** — достаточная для точного воспроизведения;
- кэш по точному входу. Ключ включает личность участника, его знание норм и
  версию корпуса, см.
  [[docs/decisions/practice-becomes-norm-only-by-enactment|кодификацию]].

Инвариант: без записи период не воспроизводится, а вехи с живыми участниками
нельзя тестировать детерминированно.

## Предоставляет

Не спроектировано.

## Требует

Ничего, включая предметную область.

## Не знает

Предметной области, должностей и компетенции. Что модели можно и чего нельзя,
определяет [[docs/design/components/actors|actors]].

## Исходы и ошибки

Не спроектировано. Известные классы отказа: исчерпание бюджета, всплеск
задержки, отказ провайдера, невалидный по схеме выход.

## Шов

Да: живой вызов против записанного выхода.

## Проверяется

Реплеем по записи — гейт вехи [[docs/design/stages/live-actors|live-actors]].
Живые вызовы — отдельным версионируемым набором evals, см.
[[docs/design/testing|testing]].

## Открыто

Наблюдаемость AI-контура — метрики, стоимость вызовов, латентность,
деградация — не спроектирована, см. [[docs/open-questions|открытые вопросы]].
