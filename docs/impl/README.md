# Первая реализация

Самый нижний и самый недолговечный слой: провайдеры, транспорт, хранилище,
инструменты. **Всё здесь выбрасывается без последствий** для замысла, понятий и
устройства ядра.

Ядро пишется автономно и в памяти. Реальное хранилище появляется на вехе [[docs/design/stages/durable-storage|durable-storage]],
транспорт — на [[docs/design/stages/external-view|external-view]]. До этого содержимое каталога является рабочей гипотезой и
подлежит перепроверке перед первым спайком: цифры, ограничения и статусы
генераторов устаревают быстрее, чем пишется код.

**Ничто из `guide/` сюда не ссылается.** Это проверяется скриптом: как только
объяснение замысла начинает зависеть от выбора провайдера, слои слиплись.

- [[docs/impl/durable-commit|durable-commit]] — как один контракт фиксации
  реализуется разными механизмами;
- [[docs/impl/api-transport|api-transport]] — HTTP и gRPC наружу;
- [[docs/impl/tooling|tooling]] — хуки, генерация, инструменты по мере роста.

Источники и проверяемые утверждения — в [[docs/research/README|research]].
