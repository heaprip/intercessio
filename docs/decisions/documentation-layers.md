# Документация делится по скорости устаревания

Status: Accepted  
Proposed by: assistant  
Accepted by: author  
Зависит от: —  
Заменяет: [[docs/decisions/project-memory-and-documentation-lifecycle|project-memory-and-documentation-lifecycle]]

## Context

Прежняя раскладка делила документы по теме: продукт, предметная область,
архитектура, решения, исследования, оперативная память. Тема оказалась плохим
критерием, потому что одна и та же материя — например нормы — присутствует на
всех уровнях сразу.

Наблюдаемые последствия: один тезис излагался в шести-семи местах разными
словами; решения про инфраструктуру, которая понадобится через девять вех,
лежали в слое, который по определению не устаревает; оперативная память
разошлась с рабочим деревом на первом же коммите; читателю негде было начать и
негде закончить.

## Decision drivers

- человек должен уметь прочитать проект подряд и понять целое;
- документ, который дёшево выбросить, не должен лежать рядом с тем, который
  выбросить нельзя;
- идентификатор понятия должен читаться в тексте ссылки;
- проверяемость структуры скриптом, без проверки смысла.

## Considered options

1. Делить по теме — прежняя раскладка.
2. Делить по режиму Diátaxis: обучение, задача, справка, объяснение.
3. Делить по скорости устаревания и стоимости ошибки.

## Decision

Выбран вариант 3; форма подачи внутри слоя заимствует различение Diátaxis между
чтением подряд и справкой.

| Слой | Каталог | Устаревает, когда | Стоимость ошибки |
| --- | --- | --- | --- |
| Замысел | `guide/` | меняется, во что играют | катастрофа |
| Понятия | `concepts/` | меняется язык | высокая |
| Решения | `decisions/` | никогда — заменяются новым | средняя |
| Устройство | `design/` | меняется состав ядра | средняя |
| Реализация | `impl/` | меняется стек | нулевая, выбрасывается |
| Источники | `research/` | появляется проверка | нулевая |

Два инварианта, на которых всё держится:

1. **Глава `guide/` понятна без перехода по ссылкам.** Ссылка ведёт только
   вниз, за подробностью. Как только глава требует сходить в `concepts/`, чтобы
   её понять, — правило нарушено и текст переписывается.
2. **`guide/` не ссылается на `impl/` ни разу.** Проверяется скриптом.

Нумерация остаётся только у глав `guide/` и означает порядок чтения.
Идентификатором решения и понятия является слаг имени файла: у одного автора и
неизменяемых решений номер не даёт ни защиты от коллизий, ни устойчивости
идентичности, а в тексте ссылки читается хуже.

Каталог `.agents/` упраздняется: он не попадал в граф Obsidian, дублировал
`guide/` и расходился с ним. Оперативный снимок стал
[[docs/guide/06-where-we-are|главой 6]], нерешённое —
[[docs/open-questions|открытыми вопросами]].

## Consequences

Появляется одно место, куда можно послать человека со словами «читай подряд».
Инфраструктурный слой можно выбрасывать целиком, не трогая остального. Правки
понятий не задевают замысел.

Цена: переименование документа ломает ссылки — ловится проверкой висящих
wikilinks. Слой `guide/` требует настоящего письма, а не склейки: он не
собирается автоматически из нижних слоёв.

## Validation

Проверить через первые несколько вех: понадобилось ли добавлять седьмой слой,
и оставался ли `guide/` читаемым подряд без переходов.
