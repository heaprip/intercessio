# Хранятся факты, вычисляются следствия норм

Status: Proposed  
Proposed by: assistant (записано со слов автора)  
Accepted by: —  
Зависит от: [[docs/decisions/norms-are-inference-rules|norms-are-inference-rules]]  
Заменяет: —

## Context

Правка закона должна догонять уже существующих людей. Если действующие права
хранятся в состоянии человека, каждая правка нормы превращается в миграцию
данных, а ретроактивный ущерб становится неизмеримым.

## Decision drivers

- правка закона не должна требовать миграции;
- ретроактивный ущерб должен быть измерим, а не оцениваем;
- история решений обязана оставаться неприкосновенной;
- пересчёт обязан быть детерминированным и не требовать вызовов модели.

## Considered options

1. Хранить действующие права и обязанности в состоянии человека.
2. Хранить только факты, выводить следствия норм.
3. Гибрид: хранить с инвалидацией кэша при правке нормы.

## Decision

Выбран вариант 2.

**Хранится, с провенансом:** установленные факты, вступившие в силу решения,
занятие должностей, поданные прошения. **Вычисляется:** действующие права,
обязанности, ограничения.

Статус разрезается по той же линии: «человек имеет статус X» хранится, «что даёт
статус X» вычисляется из норм периода.

Граница фактов и выводов не меняется никогда: «орган Y решил X в периоде N» —
факт, он не пересчитывается; какие права даёт это решение — вывод, он
пересчитывается сам.

## Consequences

Правка закона автоматически догоняет существующих людей, мигрировать нечего.
Ретроактивный ущерб измеряется пересчётом состояния на период N по двум версиям
корпуса и вычитанием — детектор получается арифметикой, а не отдельной
механикой. Тот же пересчёт даёт список затронутых, то есть **порождает дела**.

Цена: полный пересчёт на период при каждой правке. Кэшируется по паре «период +
версия корпуса». Каскад — одна правка задевает многих, каждый затронутый
порождает дело — требует явной очереди с приоритетом и бюджета, иначе период
раздувается.

## Validation

Правка нормы на сценарии казуса даёт ожидаемый поимённый список затронутых.
Пересмотреть, если стоимость пересчёта станет ограничивающей на реалистичном
размере мира.
