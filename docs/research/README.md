# Исследования

Здесь хранятся датированные заметки по вопросам, где важны источники и
актуальность: институциональные модели, безопасность LLM, нормативные системы,
исторические источники и выбор технологии.

Исследование не является решением. Его результат становится основанием ADR или
обновления требования только после явного принятия автором.

Имя файла: `topic.md`. Даты не используются: хронология в этом репозитории
не несёт информации, связи несут. Вместо даты исследование указывает, что оно
обосновывает и при каком событии устаревает.

Минимальная структура:

```markdown
# Тема

Обосновывает: ADR-NNNN | требование | ничего пока
Зависит от: другое исследование или решение
Устаревает при: событие, после которого нужно перепроверить
Question: ...

## Findings
...

## Sources
- [Primary source](https://example.com)

## Applicability to Intercessio
...

## Unknowns and expiry trigger
...
```

Предпочитать первичные источники. Для изменчивой информации описывать
событие, после которого исследование нужно повторить, — оно надёжнее даты.
