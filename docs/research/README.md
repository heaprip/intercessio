# Источники

Заметки по вопросам, где важны первоисточники и актуальность: институциональные
модели, безопасность моделей, нормативные системы, исторические источники, выбор
технологии.

**Исследование не является решением.** Его результат становится основанием
только после явного принятия автором.

- [[docs/research/roman-status-and-citizenship|roman-status-and-citizenship]] —
  статус как пучок прав, частичные статусы, коллективный акт. Источники **не
  проверены**;
- [[docs/research/roman-procedure-and-offices|roman-procedure-and-offices]] —
  двухфазное рассмотрение, формула, цепочка возражений, срок магистратуры.
  Источники **не проверены**;
- [[docs/research/architecture-and-tooling-sources|architecture-and-tooling-sources]]
  — Go-интерфейсы, риски agentic-систем, инструменты;
- [[docs/research/serverless-and-storage|serverless-and-storage]] — провайдеры,
  транзакции, авторизация, транспорт.

## Формат

Имя файла — тема, слаг. Дат нет: вместо даты заметка указывает, что она
обосновывает и при каком событии устаревает — событие надёжнее даты.

```markdown
# Тема

Обосновывает: решение | требование | ничего пока
Зависит от: другое исследование или решение
Устаревает при: событие, после которого нужно перепроверить
Question: ...

## Findings
## Sources
## Applicability to Intercessio
## Unknowns and expiry trigger
```

Предпочитать первичные источники. **Непроверенный URL хуже его отсутствия:**
если ссылка не проверена, она не проставляется, а заметка честно сообщает, что
основанием ещё не является.
