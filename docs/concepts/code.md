# Кодекс

`Code`

Систематизированный [[docs/concepts/normative-document|нормативный документ]]
уровнем ниже [[docs/concepts/constitution|конституции]] и выше отдельных актов.

**Не путать с** набором условий в коде приложения: у кодекса есть версия,
период вступления и место в иерархии.
