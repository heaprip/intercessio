# Intercessio

`Intercessio`

Формальное приостановление [[docs/concepts/decision|решения]] до его
[[docs/concepts/finalization|вступления в силу]], совершаемое должностью, у
которой такая [[docs/concepts/competence|компетенция]] явно есть.

Даёт имя всему проекту и является главным наблюдаемым признаком того, что
разделение полномочий работает: у решения есть независимый тормоз.

**Не путать с** универсальной отменой любого решения и с
[[docs/concepts/review|пересмотром]] — intercessio останавливает, пересмотр
проверяет заново.
