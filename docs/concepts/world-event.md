# Событие мира

`WorldEvent`

Внешнее обстоятельство, которое [[docs/concepts/auctor|auctor]] вбрасывает в
фазе правки: неурожай, война, эпидемия, приток людей. Меняет факты о мире, но
не меняет норм и не разрешает дел.

Событие мира записывается как факт с автором и
[[docs/concepts/period|периодом]] наравне с правкой нормы.

**Не путать с** [[docs/concepts/domain-event|доменным событием]] — техническим
фактом внутри модели.
