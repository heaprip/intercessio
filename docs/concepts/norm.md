# Норма

`Norm`

Адресуемое правило внутри [[docs/concepts/normative-document|нормативного
документа]]. Наследует его уровень в иерархии.

Хранится структурно — как [[docs/concepts/inference-rule|правило вывода]].
Авторская проза является представлением, а не источником: нормой становится
только подтверждённая игроком структура.

Датируется целыми периодами: принята в N, действует с M. Случай `M < N` есть
[[docs/concepts/retroactivity|ретроактивность]]. Норма объявляет свой
[[docs/concepts/norm-kind|вид]] и может действовать на класс лиц, минуя дело.

**Не путать с** рекомендацией и с предсказанием модели.
