# Решение

`Decision`

Формальный исход, вынесенный компетентной [[docs/concepts/office|должностью]]
по версии [[docs/concepts/case|дела]]. Хранится как факт с
[[docs/concepts/provenance|провенансом]] и не пересчитывается никогда.

Решение само по себе ещё не исполнимо: между ним и
[[docs/concepts/execution|исполнением]] лежат
[[docs/concepts/intercessio|intercessio]] и
[[docs/concepts/finalization|вступление в силу]].

**Не путать с** рекомендацией, объяснением и исполнением.
