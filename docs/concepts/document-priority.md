# Приоритет документов

`DocumentPriority`

Правило разрешения конфликта норм: норма документа более высокого уровня
вытесняет норму нижнего. Отдельного механизма специальности нормы не вводится.

Приоритет отвечает на вопрос «какая из двух противоречащих норм побеждает». Он
**не** задаёт [[docs/concepts/stratum|слои стратификации]] — те выводятся из
графа предикатов и с уровнями документов не совпадают.

Приоритет спрятан за [[docs/concepts/entitlement|нормативным результатом]]:
ядро нигде не спрашивает напрямую, какой документ выше.
