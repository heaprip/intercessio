# Слой

`Stratum`

Уровень в разбиении **предикатов**, обеспечивающем корректность отрицания: если
правило для `p` отрицает `q`, то `q` вычисляется в строго более низком слое.

Слои выводятся из графа зависимостей предикатов: сильно связные компоненты,
сами слои — топологический порядок конденсации.

Отрицательное ребро внутри компоненты означает, что корпус в этой точке не
стратифицируется. Это **не отвергает** [[docs/concepts/corpus|корпус]]: вывод
трёхзначен, и затронутые предикаты получают значение «неопределённо» —
[[docs/concepts/non-liquet|non liquet]]. Остальной корпус считается как обычно.

**Слои не совпадают с уровнями документов.** Три нормы одного кодекса
регулярно попадают в три разных слоя, а норма конституции — в слой ниже
выведенного из кодекса. [[docs/concepts/document-priority|Приоритет
документов]] решает другую задачу — какой из противоречащих выводов побеждает.
Смешение этих двух вещей — самая дорогая ошибка в модели.
