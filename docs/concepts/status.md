# Статус

`Status`

Именованный [[docs/concepts/right-bundle|пучок прав]], который человек имеет.
Не позиция на одномерной шкале: `peregrinus` и `civis` различаются составом
пучка, а не «уровнем».

Факт «человек имеет статус X» хранится; «что даёт статус X» выводится из норм
[[docs/concepts/period|периода]]. Статус может быть основанием другого статуса,
поэтому образует граф зависимостей.

Всё, что даётся, должно уметь отниматься: у статуса есть явное основание утраты.

**Не путать с** [[docs/concepts/right|правом]] и с флагом «гражданин да/нет».
