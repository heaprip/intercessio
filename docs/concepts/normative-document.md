# Нормативный документ

`NormativeDocument`

Версионируемый источник [[docs/concepts/norm|норм]] с уровнем в иерархии и
периодами принятия и вступления. Уровни: конституция выше кодексов, кодексы
выше отдельных актов.

Версия документа — новое значение, а не изменение прежнего: старые версии нужны
для [[docs/concepts/impact|пересчёта затронутых]].

**Не путать с** [[docs/concepts/decision|решением]] по отдельному делу.
