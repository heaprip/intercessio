# Команда

`Command`

Адресованное владельцу модели намерение изменить состояние. Может быть
отклонена — в частности как [[docs/concepts/ultra-vires|действие вне
компетенции]].

**Не путать с** [[docs/concepts/petition|прошением]] человека и с
[[docs/concepts/domain-event|доменным событием]].
