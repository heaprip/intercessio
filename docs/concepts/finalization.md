# Вступление в силу

`Finalization`

Переход, после которого [[docs/concepts/decision|решение]] разрешено
[[docs/concepts/execution|исполнять]]. Обязателен: исполнение без него движок
не допускает независимо от содержания норм.

**Не путать с** простым сохранением черновика решения.
