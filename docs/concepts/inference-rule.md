# Правило вывода

`InferenceRule`

Структурная форма [[docs/concepts/norm|нормы]]: голова и тело из литералов, в
духе Datalog со стратифицированным отрицанием. Заимствуется модель вычисления,
а не язык и не синтаксис.

Правила строятся из данных сценария и вычисляются циклом до неподвижной точки
по [[docs/concepts/stratum|слоям]]. Языковая модель не вычисляет условие в
рантайме: это ломало бы воспроизводимость периода и фактически делало бы текст
модели нормой.

Два свойства, ради которых выбрана эта форма: вывод на конечных данных всегда
завершается — игрок не может написать норму, из-за которой ход не закончится, —
и [[docs/concepts/derivation-trace|трасса]] получается даром.
