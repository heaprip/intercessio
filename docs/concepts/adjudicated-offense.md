# Запись о проступке

`AdjudicatedOffense`

Последствие вступившего в силу [[docs/concepts/decision|решения]] об
установленном нарушении. Хранится как факт с
[[docs/concepts/provenance|провенансом]] и не пересчитывается.

Это конец цепочки, а не её начало: [[docs/concepts/violation|нарушение]]
выводится движком → становится поводом для [[docs/concepts/case|дела]] →
компетентная должность выносит решение → решение вступает в силу → появляется
запись о проступке.

**Не путать с** нарушением, обвинением, подозрением и тем более со скрытой
оценкой человека. Ни один шаг цепочки нельзя пропустить: выведенное движком
нарушение проступком само по себе не является.
