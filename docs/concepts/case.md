# Дело

`Case`

Рамка рассмотрения [[docs/concepts/petition|прошения]] или спора: участники,
подлежащий проверке вопрос, установленные по нему факты,
[[docs/concepts/decision|решение]], возможная
[[docs/concepts/intercessio|intercessio]] и
[[docs/concepts/execution|исполнение]].

Дело может жить дольше одного [[docs/concepts/period|периода]] и имеет
объявленный предельный срок, по истечении которого прекращается само. Пока дело
не завершено, оно идёт по **действующему** корпусу, а не по замороженному на
момент подачи.

**Не путать с** человеком и с окончательным решением.
